# Shop Khata — Setup Guide

## 1. Get the file
After buying on Gumroad, download `shop-khata.xlsx`.

## 2. Open it
- **Excel:** just double-click the file.
- **Google Sheets:** go to Google Drive → New → File upload, upload the file,
  then open it with Google Sheets (or File → Import → Upload).

## 3. Delete the examples
The Daily Entry sheet has yellow rows marked EXAMPLE. Delete those rows
before you start. They are only there to show how it works.

## 4. Type your daily sales and expenses
In **Daily Entry**, type one row per sale or expense:
- Date, what it was, and the amount in Sale or Expense.

## 5. Udhaar (credit) rules
- **Sale on udhaar:** type the amount in Sale AND in Udhaar Given, plus the
  customer name.
- **Customer pays back:** type the amount in Udhaar Received with their name.
- The **Dashboard** and **Udhaar Ledger** update automatically. You never
  type totals yourself.

## 6. New customers
In **Udhaar Ledger**, type the customer name in column A, then copy the
formulas from the row above down to the new row.

## 7. Check your month
**Monthly Summary** shows each month's sales, expenses, and profit. To add
more months, copy a row down and change the month.

## Tips
- The Dashboard has a date box (it shows today). Change that date to see any
  other day's figures.
- All money is in PKR (Rs). All totals are formulas — if a number looks
  wrong, check the Daily Entry rows, not the totals.
